一、项目原始状态（竞赛原型）
----------------------------------------------------------------
【原始代码量】
- Python 后端文件：约 12 个
- Vue 前端文件：约 8 个
- 总体规模：轻量竞赛原型

【原始功能】
1. 文档上传与解析（docx/xlsx/md/txt）
   - 使用 Docling 解析 + fallback 轻量解析
   - 分块写入 ChromaDB 本地向量库

2. 智能问答（RAG）
   - 基于 ChromaDB 向量检索
   - LangChain + LLM 生成回答
   - 支持 DeepSeek / GLM / OpenAI 等 API

3. 模板表格自动填写
   - 上传 docx/xlsx 模板
   - 从知识库检索数据，LLM 提取并填入
   - 精细/粗略两种检索模式

4. 前端界面
   - Vue 3 + 自定义 CSS 暗色主题
   - 4 个页面：首页、文档上传、智能问答、表格填写
   - 无用户系统，无数据库，无日志

【原始技术栈】
- 后端：FastAPI + LangChain + ChromaDB
- 前端：Vue 3 + Pinia + Vue Router（无 UI 组件库）
- 桌面端：PyInstaller + pywebview


二、本次新增与修改内容
----------------------------------------------------------------

【竞赛功能优化（比赛前）】
- 表格填写：按字段分别检索（替代拼接表头搜索），大幅提升准确率
- 表格填写：LLM Prompt 优化，强调提取所有行、保持原始值
- 表格填写：JSON 解析增加重试机制，处理 markdown 代码块包裹
- 表格填写：粗略模式增加 6000 字符截断，防止上下文溢出
- 文档分块：改为 500 字符 + 100 字符重叠，减少信息切断
- 知识库：文档入库去重（同名文件覆盖而非追加）
- 前端：修复精细/粗略切换标签反转 bug
- 前端：表格填写页面显示响应耗时
- 前端：上传页面显示已入库文档列表 + 一键清空知识库
- 新增模块一（文档智能操作交互）：
  * core/doc_operator.py — 自然语言指令操作文档
  * 支持 docx 格式修改（加粗/居中/替换/删除/插入）并导出
  * server/routes/doc_ops.py + 前端 DocOpsView.vue
