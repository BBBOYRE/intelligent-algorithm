一、快速启动
----------------------------------------------------------------
【环境要求】
- Python 3.12（venv 已配置好，路径：./venv）
- Node.js 22+（前端依赖已安装）

【启动后端】
cd "D:\智能算法\intelligent-algorithm-leziren (2)\intelligent-algorithm-leziren"
.\venv\Scripts\python.exe main.py

【启动后端（Web模式，浏览器访问）】
.\venv\Scripts\python.exe main.py --web
然后浏览器打开 http://127.0.0.1:8199

【重新构建前端（改了前端代码后必须执行）】
cd frontend
npm run build

【安装新依赖（如果 requirements.txt 有变化）】
.\venv\Scripts\pip.exe install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt


二、关键配置文件
----------------------------------------------------------------
【.env 文件】（项目根目录，不提交 git）
AUTH_DISABLED=false        # true=免登录，false=启用登录注册
LLM_PROVIDER=openai
LLM_API_KEY=xxx            # 当前使用智谱 GLM-4-Flash
LLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4
LLM_MODEL=glm-4-flash
EMBEDDING_PROVIDER=local
EMBEDDING_MODEL=BAAI/bge-small-zh-v1.5

【config.py】
- DATABASE_URL 默认 sqlite:///data/db/app.db
- JWT_SECRET_KEY 生产环境务必修改
- AUTH_DISABLED=true 时所有请求使用默认管理员账号（免登录）


三、数据库
----------------------------------------------------------------
- 类型：SQLite（开发），可切换 PostgreSQL（生产）
- 位置：data/db/app.db
- 自动建表：启动时 init_db() 自动创建所有表，无需手动迁移
- 表结构：users / documents / knowledge_bases / audit_logs

【重置数据库】
删除 data/db/app.db 文件，重启后自动重建


四、知识库
----------------------------------------------------------------
- 向量库：ChromaDB，数据存储在 data/chroma_db/
- 文档备份：data/chroma_db/_parsed_docs_storage.json
- Embedding 模型：BAAI/bge-small-zh-v1.5（首次运行自动下载到 data/models/）
- 每个用户有独立的 ChromaDB collection（格式：kb_{user_id}_default）

【重置知识库】
方式1：登录后在"文档上传"页面点击"清空知识库"
方式2：删除 data/chroma_db/ 目录，重启后自动重建


五、API 接口一览
----------------------------------------------------------------
认证：
  POST /api/auth/register    注册
  POST /api/auth/login       登录（返回 JWT token）
  GET  /api/auth/me          获取当前用户信息

文档：
  POST /api/documents/upload         同步上传（≤5个文件）
  POST /api/documents/upload-async   异步上传（>5个文件，返回 task_id）

任务：
  GET  /api/tasks/{task_id}   查询任务进度

知识库：
  GET    /api/kb/stats              知识库统计
  GET    /api/kb/list               知识库列表
  POST   /api/kb/create             创建知识库
  DELETE /api/kb/{id}               删除知识库
  DELETE /api/kb/clear              清空当前知识库
  GET    /api/kb/documents          文档列表（支持搜索/筛选）
  DELETE /api/kb/documents/{name}   删除单个文档

问答：
  POST /api/chat              RAG 智能问答

表格填写：
  POST /api/table/preview     预览填写结果（返回 JSON，不写文件）
  POST /api/table/fill        执行填写并生成文件

文档操作：
  POST /api/doc-ops/execute   自然语言指令操作文档

文件下载：
  GET  /api/files/download?path=xxx   下载生成的文件

分析：
  GET  /api/analytics/overview   使用统计总览
  GET  /api/analytics/usage      按天趋势数据
  GET  /api/audit/logs           操作日志（分页）


六、前端页面路由
----------------------------------------------------------------
/#/login          登录/注册页

八、注意事项
----------------------------------------------------------------
1. 修改前端代码后必须重新 npm run build，否则桌面端看不到变化
2. 修改后端代码后必须重启 python main.py
3. 改了分块策略（chunk_size/overlap）后，已入库文档需要重新上传
4. 生产环境部署时务必修改 .env 中的 JWT_SECRET_KEY
5. AUTH_DISABLED=true 时任何人都能访问，仅适合本地私有化使用
6. 知识库数据在 data/ 目录，不要误删
7. C 盘空间不足时 pip 安装会失败，可用 --cache-dir 指向 D 盘
