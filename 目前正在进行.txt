 Phase 1：基础设施（用户系统 + 前端重构）

     1A. 数据库层

     - 新建 server/database.py — SQLAlchemy 引擎 + session 工厂 + get_db 依赖
     - 新建 server/models/user.py — 用户表（id, email, username, hashed_password, role, is_active, created_at）
     - 新建 server/models/document.py — 文档记录表（id, user_id, file_name, file_size, format, chunk_count, status,
     created_at）
     - 新建 server/models/knowledge_base_model.py — 知识库表（id, user_id, name, collection_name, description,
     created_at）
     - 新建 alembic/ — 数据库迁移配置
     - 修改 config.py — 添加 DATABASE_URL、AUTH_DISABLED、DEPLOYMENT_MODE
     - 修改 requirements.txt — 添加 sqlalchemy, alembic, python-jose, passlib

     1B. 认证系统

     - 新建 server/auth/security.py — 密码哈希（bcrypt）、JWT 创建/验证、get_current_user 依赖
     - 新建 server/auth/schemas.py — UserCreate, UserLogin, TokenResponse, UserProfile
     - 新建 server/routes/auth.py — /api/auth/register, /api/auth/login, /api/auth/me
     - 修改 所有现有路由 — 添加 Depends(get_current_user)，按 user_id 隔离数据
     - 私有化部署可通过 AUTH_DISABLED=true 跳过认证

     1C. 多知识库隔离

     - 修改 core/knowledge_base.py — 按 user_id + kb_id 生成独立 ChromaDB collection
     - 修改 server/dependencies.py — get_kb(user_id, kb_id) 解析正确的 collection
     - 修改 server/routes/kb.py — 知识库 CRUD（创建、列表、删除、切换）

     1D. 前端重构

     - 引入 Naive UI 组件库（Vue 3 原生、暗色主题、中文支持、tree-shakeable）
     - 引入 axios 替代 fetch（拦截器注入 auth token）
     - 引入 @vicons/ionicons5 替代 emoji 图标
     - 新建 src/stores/auth.js — 用户状态、token 管理、登录/登出
     - 新建 src/api/http.js — axios 实例 + 请求/响应拦截器
     - 新建 src/views/LoginView.vue — 登录/注册页
     - 新建 src/views/DashboardView.vue — 真正的仪表盘（替代 HomeView）
     - 新建 src/views/SettingsView.vue — 用户设置、密码修改、LLM 配置
     - 新建 src/layouts/AuthLayout.vue — 登录页布局（无侧边栏）
     - 新建 src/layouts/MainLayout.vue — 主布局（侧边栏 + 头部 + 内容区）
     - 新建 src/components/KBSelector.vue — 侧边栏知识库切换下拉
     - 修改 src/App.vue — 根据认证状态切换布局
     - 修改 src/router/index.js — 路由守卫 + requiresAuth meta
     - 修改 src/components/AppHeader.vue — 用户头像下拉菜单
     - 修改 src/components/AppSidebar.vue — 知识库选择器 + 用户信息

     Phase 2：核心功能增强

     2A. 批量处理 + 实时进度

     - 新建 server/tasks/task_manager.py — asyncio 任务队列，任务 ID + 状态 + 进度
     - 新建 server/tasks/document_tasks.py — 批量文档处理任务
     - 新建 server/routes/tasks.py — GET /api/tasks/{id} 轮询进度
     - 新建 src/components/TaskProgress.vue — 可复用进度组件
     - 修改 server/routes/documents.py — 上传变为异步，返回 task_id
     - 修改 core/document_parser.py — 增加 PDF（docling 已支持）、CSV、HTML 格式

     2B. 知识库高级管理

     - 新建 src/views/KnowledgeBaseView.vue — 知识库详情页（文档列表、搜索、删除单文档）
     - 新建 src/components/DocumentList.vue — 可排序/筛选的文档表格
     - 新建 src/components/SearchPanel.vue — 高级搜索（日期、格式、来源筛选）
     - 修改 server/routes/kb.py — 文档列表、单文档删除、带筛选的搜索
     - 修改 core/knowledge_base.py — 添加 remove_document(file_name) 方法

     2C. 表格填写增强

     - 修改 core/table_filler.py — 新增 preview_fill() 返回结构化数据（不写文件）
     - 修改 server/routes/table.py — 新增 POST /api/table/preview 预览接口
     - 修改 src/views/TableFillView.vue — 填写后先预览可编辑表格，确认后再下载

     2D. 文档对比

     - 新建 core/doc_comparator.py — 两文档 LLM 对比分析
     - 新建 src/views/DocCompareView.vue — 并排对比视图
     - 修改 server/routes/doc_ops.py — 新增 POST /api/doc-ops/compare

     2E. 多格式导出

     - 新建 utils/export_utils.py — docx→PDF、数据→CSV/JSON 转换
     - 修改 server/routes/files.py — 新增 format 参数支持格式转换下载

     - 新建 src/views/AnalyticsView.vue — 图表仪表盘
     - 新建 src/components/charts/UsageChart.vue — 使用趋势图

     实施顺序

     Phase 1A → 1B → 1C → 1D（严格顺序，约 4-6 周）
         ↓
     Phase 2A / 2B / 2C（可并行，约 3-4 周）
         ↓
     Phase 3A → 3B / 3C（约 2-3 周）
         ↓
     Phase 4A → 4B → 4C → 4D（约 4-6 周）

     验证方式

     - Phase 1 完成后：能注册登录、创建知识库、上传文档、隔离数据
     - Phase 2 完成后：批量上传有进度、表格填写可预览编辑、支持更多格式
     - Phase 3 完成后：能看到使用统计图表、操作日志可查询
     - Phase 4 完成后：团队协作、API 接入、Webhook 通知
